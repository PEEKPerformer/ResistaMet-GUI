# Citation

If you use ResistaMet GUI in your research, please cite:

```
Ferland, B. (2026). ResistaMet GUI: An Open-Source Electrical Measurement Suite
for Keithley Sourcemeters [Software]. Zenodo. https://doi.org/10.5281/zenodo.19919751
```

The DOI above is the **concept DOI** and always resolves to the latest archived version. Zenodo also mints a per-version DOI for citing a specific release; the latest is [10.5281/zenodo.20384975](https://doi.org/10.5281/zenodo.20384975) for v1.12.0.

A [`CITATION.cff`](https://github.com/PEEKPerformer/ResistaMet-GUI/blob/main/CITATION.cff) is included in the repository for machine-readable citation metadata. GitHub auto-renders a "Cite this repository" button from it.
