# Citation

If you use ResistaMet GUI in your research, please cite it.

## Concept DOI (recommended for most citations)

The **concept DOI** always resolves to the latest archived version on Zenodo:

```
Ferland, B. (2026). ResistaMet GUI: An Open-Source Electrical Measurement Suite
for Keithley Sourcemeters [Software]. Zenodo. https://doi.org/10.5281/zenodo.19919751
```

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.19919751.svg)](https://doi.org/10.5281/zenodo.19919751)

## Per-version DOI (for reproducibility-critical citations)

Each tagged release also gets its own DOI. To cite a specific version (recommended when reproducibility matters), browse the **Versions** sidebar on the [Zenodo record](https://doi.org/10.5281/zenodo.19919751) and use that release's DOI.

## BibTeX

```bibtex
@software{ferland_resistamet_gui,
  author    = {Ferland, Brenden},
  title     = {{ResistaMet GUI: An Open-Source Electrical Measurement Suite
               for Keithley Sourcemeters}},
  year      = {2026},
  publisher = {Zenodo},
  doi       = {10.5281/zenodo.19919751},
  url       = {https://doi.org/10.5281/zenodo.19919751}
}
```

A machine-readable [`CITATION.cff`](https://github.com/PEEKPerformer/ResistaMet-GUI/blob/main/CITATION.cff) lives in the repo. GitHub auto-renders a **"Cite this repository"** button from it.
